# BILLONARIA

**Compra el mundo, quiebra a tus amigos.**

Juego de propiedades 3D con ediciones temáticas (Metrópolis, Frontera Estelar, Archipiélago Azul, Reinos Encantados), hasta 6 jugadores, fichas, subastas y bots.

▶ **Juega ahora:** https://gamexic.github.io/billonaria/

Funciona directamente en el navegador (necesita WebGL y conexión para cargar librerías y fuentes). Sin instalación.

## Música

Música de fondo con licencia **CC0 1.0 (dominio público)**: se puede usar en proyectos comerciales y no exige crédito. Cada edición tiene su lista:

| Edición | Pistas |
|---|---|
| Metrópolis | `lofi-tea`, `lofi-chill-loop` |
| Frontera Estelar | `contemplation`, `lofi-lobby` |
| Archipiélago Azul | `cozy-acoustic`, `ambient-piano` |
| Reinos Encantados | `inspiring-orchestral`, `ambient-piano` |

Los archivos están en `music/` y el botón 🎵 del juego los silencia. Las pistas vienen de la biblioteca CC0 de Frank (normalizadas a −16 LUFS, mp3 96 kbps).
